## 💡 The Inspiration

Traditional focus tools and website blockers fall into two categories:
1. **Boring & Easily Bypassed**: Standard popup warnings or URL redirect screens that you immediately close or bypass in 2 seconds.
2. **Heavy & Intrusive**: Enterprise surveillance software that feels punitive and stressful.

We wanted to build something radically different: a tool that makes staying focused **hilarious, adorable, visceral, and unforgettable**. TabbyPatrol gives you a loyal digital desktop companion—a lazy but deadly tactical sniper kitten that chills on its plush cushion, makes biscuits when you're working, and literally mounts a **high-caliber tactical sniper rifle to rapid-fire laser bullets at multiple procrastination tabs** the moment you slip up!

## ✨ Key Features

### 🎯 1. Tactical Sniper Rifle & Laser-Fast Railgun Bullets
- **Zero Browser Extensions Needed**: Operates across **Google Chrome, Microsoft Edge, Brave, Firefox, and Opera** completely autonomously via Windows UI Automation & Win32 APIs.
- **The Awakening**: The kitten wakes up slightly on its pillow (`- o`), detecting distraction tabs in the browser.
- **Tactical Sniper Mount**: Deploys a matte-black sniper rifle on an elevated bipod with high-magnification scope and glowing cyan objective lens glint.
- **Crimson Laser Lock**: Casts a high-intensity red targeting laser with glowing reticle crosshairs onto the target tab.
- **Hyper-Velocity Railgun Bullet**: Pulls the trigger and fires a blazing laser projectile at **175 px/frame**, drawing dual-energy laser tracer beams and ejecting tumbling brass casings into the air.
- **Multi-Target Quick Succession (Rapid Fire)**:
  - If two or more distraction tabs are opened simultaneously, Tabby enters **Rapid Fire Mode**!
  - Snipes the first tab, instantly cycles the tactical bolt with an audible `CH-CHK!`, locks onto the next target, and double-taps it in lightning-fast succession.
- **Violent Impact & Physical Tab Closure**:
  - Entire screen shakes violently with sonic shockwave rings: `⚡ BANG! SNIPED! 🎯💥`.
  - Dispatches targeted input closure (`Ctrl+W` or tab close coordinate click) directly to eliminate the distraction.
- **Smug Sniper Cat**: The kitten raises the smoking barrel, blows away a puff of smoke, gives a smug wink (`^ _ ~`), and curls right back up into a loaf to resume snoozing!

### 🛋️ 2. The Corner Pillow Roost
- Tucked neatly into the bottom-right corner of your desktop.
- **Compact & Cozy**: Petite ~54px kitten on a stylish ~108px tufted cushion with golden corner tassels.
- **Adorable Behaviors**: Snoozing loaf with animated `z Z Z` bubbles, sitting upright while blinking, and **making biscuits / kneading paws** on the cushion!
- **Fully Draggable**: Click and drag the pillow anywhere on your screen.
- **Pillow Styles**: Strawberry Pink, Royal Lavender, or Mint Cloud.

### 🖥️ 3. AI Agent Command Center (HUD)
- View real-time AI Agent reasoning logs ("Thought Feed").
- Add or remove custom blocked rules / keywords.
- Test simulated sniper arrow shots anytime.

## 🚀 Quick Start Guide

### Option A: One-Click Quick Setup (Judges & Reviewers)
Double-click `setup.bat`. It will automatically check your Python environment, install required dependencies from `requirements.txt`, and launch the app!

### Option B: Manual Setup
```bash
# 1. Clone repository
git clone https://github.com/your-username/tabbypatrol.git
cd tabbypatrol

# 2. Install dependencies (Pillow & NumPy)
pip install -r requirements.txt

# 3. Launch TabbyPatrol
python overlay/tabby_overlay.py
```
